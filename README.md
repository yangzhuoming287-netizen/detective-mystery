# 逆证 · 侦探推理（Detective Mystery）

手机网页推理游戏，玩法参考《逆转裁判》：**现场调查 → 收集证物 → 询问证人 → 法庭对决**。

## 四个案件（由易到难）
1. **书房里的沉默**（教学）— 大学教授死于反锁的书房，密室是真是假？
2. **赝品**（简单）— 美术馆长中毒身亡，名画被调包，监控只断了 3 分钟
3. **钟楼**（中等）— 建筑师死在钟楼里，停摆的齿轮停在 3:47
4. **替身**（困难）— 两个目击者给出完全相反的描述，死者到底是谁？

## 玩法
- **调查**：点击场景里闪烁的金圈，查看细节并收集证物
- **询问**：点击场景中的人物，选择问题追问；关键处可用「出示证物」当场戳穿对方
- **法庭**：证物足够后点「上法庭」，对每条证言选择「追问」或「出示证物」；出示正确 → **异议あり！**，出示错误 → 扣一次机会（共 3 次）
- 进度自动保存在浏览器本地
